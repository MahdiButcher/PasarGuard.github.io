发现可与 PasarGuard 配合使用的开源项目——订阅模板、数据库工具、客户端等。项目按类别分组，并按 GitHub 星标排序（每次文档部署时更新）。

<Callout type="info" title="第三方项目">
  未标注 **官方** 的项目由社区维护。在生产环境使用前，请先审阅源码与许可证。
</Callout>

## 提交你的项目

只要满足以下条件，任何人都可以提交项目：

- **开源** — 公开仓库，并有明确许可证
- **有用** — 能改善 PasarGuard 用户或运维者的体验

提交 pull request，在 [`src/data/community-projects.ts`](https://github.com/PasarGuard/PasarGuard.github.io/blob/main/src/data/community-projects.ts) 中新增条目。请附上简短描述并选择合适分类。横幅与图标为可选。
