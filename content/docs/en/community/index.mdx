## Submit your project

Anyone can submit a project if it is:

- **Open source** — public repository with a clear license
- **Helpful** — improves the PasarGuard experience for users or operators

Open a pull request that adds an entry to [`src/data/community-projects.ts`](https://github.com/PasarGuard/PasarGuard.github.io/blob/main/src/data/community-projects.ts). Include a short description and pick the right category. Banner and icon images are optional.
