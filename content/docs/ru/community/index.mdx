Открытые проекты, которые работают с PasarGuard — шаблоны подписки, инструменты для БД, клиенты и другое. Проекты сгруппированы по категориям и отсортированы по звёздам GitHub (обновляются при каждом деплое документации).

<Callout type="info" title="Сторонние проекты">
  Проекты без метки **Официальный** поддерживаются сообществом. Перед использованием в продакшене проверьте исходный код и лицензию.
</Callout>

## Как добавить проект

Любой может предложить проект, если он:

- **Open source** — публичный репозиторий с понятной лицензией
- **Полезный** — улучшает опыт пользователей или операторов PasarGuard

Откройте pull request и добавьте запись в [`src/data/community-projects.ts`](https://github.com/PasarGuard/PasarGuard.github.io/blob/main/src/data/community-projects.ts). Укажите краткое описание и подходящую категорию. Баннер и иконка необязательны.
